# ICMP Flood Denial of Service - Attacker Reference Guide

This folder documents standard ICMP flooding commands and theoretical parameters using the `hping3` utility against a designated private target (e.g., `192.168.56.20`).

## 1. Overview of ICMP Floods
An ICMP flood sends a high volume of ICMP Echo Request (ping) packets to a target machine, forcing it to spend CPU resources processing and replying to each request. This maps to **MITRE ATT&CK T1498 (Network Denial of Service)**.

## 2. Command Reference

### Standard High-Rate Ping
Sends standard echo requests with zero delay (flood mode), attempting to saturate the target's link or processing limits.
```bash
hping3 -1 --flood 192.168.56.20
```
* **`-1`**: Specifies ICMP mode.
* **`--flood`**: Sends packets as fast as possible, ignoring incoming replies.

### Flooding with Custom Payload Size
Sends larger ICMP packets to consume target link bandwidth.
```bash
hping3 -1 --flood -d 1200 192.168.56.20
```
* **`-d 1200`**: Sets the data payload size to 1200 bytes.

## 3. Network Detection Signatures
* Massive, sustained rate of ICMP Type 8 (Echo Request) packets arriving at the target interface.
* Corresponding spikes in ICMP Type 0 (Echo Reply) outgoing traffic, unless blocked.
* Log alerts generated by iptables limit modules or IDS platforms indicating high ICMP transaction rates.
